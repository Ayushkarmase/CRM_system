========================================
DeskFlow - Customer Support Operations
========================================

--- OPTION 1: ONE-CLICK START ---
Double-click `start_all.bat` (or run `.\start_all.bat` in terminal)
This opens both backend and frontend in separate windows.

--- OPTION 2: RUN MANUALLY IN SEPARATE TERMINALS ---

Terminal 1 (Backend):
cd backend
.\venv\Scripts\uvicorn.exe app.main:app --reload --port 8000
-> Runs at http://localhost:8000 (API Docs at http://localhost:8000/docs)

Terminal 2 (Frontend):
cd frontend
npm run dev
-> Runs at http://localhost:5173

--- OPTION 3: RUN TESTS ---
.\backend\venv\Scripts\pytest.exe
